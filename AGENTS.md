# ansi-to-tui-kotlin - Agent Guidelines

This repository is a Kotlin port. When porting/updating code, follow these conventions:

## File naming (REQUIRED)

- Kotlin source filenames must be `PascalCase.kt`.
- Do not introduce lowercase-basename Kotlin files like `parser.kt`, `error.kt`, `package-info.kt`.
- When translating from upstream naming, use `snake_case.rs` → `PascalCase.kt`.
